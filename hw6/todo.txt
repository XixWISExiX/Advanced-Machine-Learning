DONE 2) Create SimpleRNN Model

----Architecture----
	Embedding layer
	Conv1D layer w/t striding
	Loop
		SimpleRNN layer (return sequences set to True)
		1D average pooling
	SimpleRNN layer (return sequences set to False)
	Loop
		Dense layer
	Dense layer (softmax output)
	
DONE 3) Create GRU (Gated Recurrent Units) Model

----Architecture----
	Embedding layer
	Conv1D layer w/t striding
	Loop
		GRU layer (return sequences set to True)
		1D average pooling
	GRU layer (return sequences set to False)
	Loop
		Dense layer
	Dense layer (softmax output)

DONE 4) Create Multi-Headed Self Attention Model

----Architecture----
	Embedding layer
	PositionalEncoding layer (use the default 'add' combination type)
	Conv1D layer w/t striding
	Loop
		MHA Layers (this has 2 arguments K/V and Q)
		1D average pooling
	GlobalMaxPooling1D (reduces set of hyper tokens to one hyper token)
	Loop
		Dense layer
	Dense layer (softmax output)
		
* use sparse categorical accuracy for ease of use
* add model_type_RNN parameter [0,1,2] for the 3 different models
