# Important File Locations & Details

- **cnn_classifier.py** generates the convolutional neural networks.
- **plot_generator.py** is used to generate images for figures 3-5.
- Plots 1 and 2 are generated by using the values stored in weights and biases.
- **.sh files** are given in the below sub sections.

## How to train the Shallow Model

You must type
`sbatch --array=0-4 hw3.sh`

## How to train the Deep Model

You must type
`sbatch --array=0-4 hw3_deep.sh`

## How to generates plots with the given models (both shallow and deep)

You must type
`sbatch --array=0-4 hw3_plots.sh`
